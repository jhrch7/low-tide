LOW TIDE — browser game

Open the hosted HTTPS link supplied with this build on a phone or computer. Each person has an independent single-player save.

Portable computer run: install Node.js20 or later, unzip this complete folder, open a terminal in it and run: node run.mjs
Then open http://127.0.0.1:8080 . No npm installation, account, API key or JOS service is needed. Opening index.html directly as a file is unreliable for browser modules/assets.

Phone on your own Wi-Fi: run node run.mjs --lan on the computer and open http://YOUR-COMPUTER-LAN-IP:8080 on the phone, using its actual Wi-Fi address. Keep the computer running. Internet friends need a public HTTPS static host; a local file/address is not an internet link. This server serves only this build’s allowlisted static files.

Hosting: upload the contents of this folder to any permitted static HTTPS host. All runtime assets are local. Preserve subfolders and serve .js as JavaScript and .wasm as application/wasm. No server game logic, multiplayer, database or credentials are required.

Touch: left stick move/steer, drag scene look, pinch zoom, Use/Enter/Drive interact, More opens reload/supplies/photo. Gas accelerates; Brake stops/reverses. Switch selects the sibling. Journal has story, map, work, island life and options. Keyboard: WASD, Shift run, E use, Q switch, F fire, R reload, C crouch, G horn, H yield, T kit, P photo, M journal.

Start with Mara’s Salt in the Engine or switch to Nico’s The Returned Badge. Joint leads unlock after both chains progress. The unselected sibling has routines and scripted/support roles. Bahía motor club’s free demonstrators are marked in the Photo passport page.

Saving: current browser/origin only; export from Options before clearing browser data or moving hosts. Import on the other browser. The previous valid save is recoverable; story restart restores its full starting save. Browsers may evict storage.
